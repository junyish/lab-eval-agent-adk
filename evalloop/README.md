# EvalLoop Evaluation Harness

This directory was generated by EvalLoop for the criteria pack `bigquery_agent_safety`.

## Contents
- `criteria/bigquery_agent_safety.yaml`: Declarative criteria pack compiled from requirements.
- `test_criteria.py`: Pytest suite evaluating criteria against recorded execution traces.
- `guardrail.py`: ADK `EvalLoopPlugin` runtime guardrail for active prevention (kept for reference; wire the guardrail as shown below).

## Running Offline Verification
Execute all mechanised criteria against recorded traces:
```bash
pytest evalloop/test_criteria.py -v
```

## Enabling Runtime Guardrails in ADK
Load the criteria pack with the installed `evalloop` package's `EvalLoopPlugin`
(path relative to the repository root):
```python
from google.adk.apps import App
from evalloop.adk import EvalLoopPlugin

app = App(
    ...,
    plugins=[EvalLoopPlugin.from_file("evalloop/criteria/bigquery_agent_safety.yaml")],
)
```

Do not use `from evalloop.guardrail import get_guardrail_plugin`: this directory
has no `__init__.py`, so once the `evalloop` package is installed it takes
precedence and `evalloop.guardrail` raises `ModuleNotFoundError`.
