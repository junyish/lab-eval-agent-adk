# EvalLoop Evaluation Harness

This directory was generated by EvalLoop for the criteria pack `bigquery_agent_safety`.

## Contents
- `criteria/bigquery_agent_safety.yaml`: Declarative criteria pack compiled from requirements.
- `test_criteria.py`: Pytest suite evaluating criteria against recorded execution traces.
- `guardrail.py`: ADK `EvalLoopPlugin` runtime guardrail for active prevention.

## Running Offline Verification
Execute all mechanised criteria against recorded traces:
```bash
pytest evalloop/test_criteria.py -v
```

## Enabling Runtime Guardrails in ADK
Add the generated guardrail plugin to your agent or app:
```python
from google.adk.apps import App
from evalloop.guardrail import get_guardrail_plugin

app = App(
    ...,
    plugins=[get_guardrail_plugin()],
)
```
